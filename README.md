# FB Tools bookmarklet

Статическая страница установки bookmarklet для Chrome. Проект основан на публичном репозитории `AntonCocuska/fb-tools-bookmarklet` и сохраняет его историю Git.

## Добавлено

- массовая загрузка существующих каталогов выбранного Business Manager;
- ввод строк `старый ID в названии<Tab>новый ID`;
- поиск каталога по текущему названию и массовая замена старых ID на новые без изменения внутреннего `catalog_id`;
- подтверждение операции, журнал результата и задержка между запросами;
- проверка пустых строк и повторяющихся ID.

## Размещение на GitHub Pages

В настройках репозитория выберите **Pages → Deploy from a branch → main / root**. Установочная страница будет доступна по адресу GitHub Pages этого репозитория.

## Важно

Bookmarklet выполняется внутри активной сессии Facebook. Не публикуйте токены и данные банковских карт. Операции Kill необратимы; перед их запуском внимательно проверяйте выбранный рекламный кабинет.
